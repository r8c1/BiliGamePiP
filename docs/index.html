常见问题与安全说明

为什么软件启动时会请求管理员权限（UAC）？安全吗？

《原神》《明日方舟：终末地》等游戏在 Windows 上常以管理员权限运行。受 Windows UIPI 特权隔离限制，普通权限工具在管理员游戏前台运行时可能收不到全局快捷键。本软件以同等权限运行，仅调用标准 Win32 RegisterHotKey，完全不接触游戏进程、不注入 DLL、不模拟键鼠，源代码在 GitHub 完全公开。

进游戏后小窗被游戏画面盖住了怎么办？

请在游戏内「画面设置」中将显示模式改为 无边框窗口化。Windows 的独占全屏模式会覆盖所有桌面置顶窗口，改为无边框窗口化即可完美显示小窗且几乎无性能损耗。

下载安装时 Windows 弹出“已保护你的电脑”蓝色提示怎么办？

由于个人开源软件未购买商业代码签名证书，Windows SmartScreen 首次遇到新版本安装包时会给出常规提示。点击提示框里的「更多信息」→「仍要运行」即可，所有安装包均由 GitHub Actions 官方云端环境公开构建。

小键盘数字键按了没反应？

请确认键盘的 NumLock 指示灯处于开启状态。如果你的键盘没有小键盘（如 68 / 87 配列），可以点击软件右上角「⚙ 快捷键」，改绑为 Alt + ← / ↓ / → 或其他顺手的组合键。
