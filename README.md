# BiliGamePiP

专为《原神》《明日方舟：终末地》等 Windows 游戏玩家设计的 **B 站独立置顶小窗 + 全局快捷键控制工具**。
无需安装浏览器插件、无需切出游戏，一个 Windows 安装包即可使用。

## 功能特性

- **真正单安装包，免配置**：基于 Windows 10/11 原生 Edge WebView2，内置完整 B 站网页（扫码登录一次永久保存，支持弹幕、历史记录、高画质）。
- **一键置顶小窗**：切入无边框置顶小窗，自动隐藏 B 站页眉与评论区只留视频与弹幕，自由拖动与缩放边缘，并记住上次位置与大小。
- **游戏内不切出控制**：通过 Windows 标准 `RegisterHotKey` 监听全局热键（**不注入游戏、不读写内存、不模拟键鼠**，反作弊友好），支持在管理员权限运行的游戏前台稳定生效。
- **防误触鼠标穿透**：一键锁定小窗为鼠标穿透，游戏内甩鼠标或开背包不会误点小窗导致失焦。
- **内置极简 OSD 提示**：快进、后退、暂停、锁定时在视频上方轻提示当前进度，随时掌握状态。

## 默认快捷键（支持界面内自由修改）

> 为彻底避开《原神》与《终末地》主键盘 `1-4` 切人按键，默认使用**小键盘 `7 / 8 / 9 / 0 / .`**（请确保键盘 `NumLock` 处于开启状态）：

| 快捷键 | 功能 |
| :--- | :--- |
| `Num7` | 后退 5 秒（支持长按连续后退） |
| `Num8` | 暂停 / 播放 |
| `Num9` | 快进 5 秒（支持长按连续快进） |
| `Num0` | 锁定 / 解锁鼠标穿透（防误触） |
| `Num.` | 切换普通选片 / 置顶小窗模式 |

## 游戏内使用注意

1. 在《原神》或《明日方舟：终末地》的画面设置中，将显示模式设为 **无边框窗口化**（独占全屏会盖住所有置顶小窗）。
2. 软件启动时会请求管理员权限（UAC），这是为了让全局快捷键在同样以管理员权限运行的游戏中生效。
3. 开启鼠标穿透后，如果忘记快捷键，也可以随时右键点击右下角**系统托盘图标**解锁或退出小窗。

## 如何生成 Windows 安装包（`BiliGamePiP-Setup-1.0.0.exe`）

### 方式一：GitHub Actions 自动云端打包（最省事，无需在电脑装任何开发环境）

1. 在 GitHub 新建一个仓库，把本文件夹推送上去。
2. 打开仓库的 **Actions** 页面 → 点击 **Build Windows Installer** → 点击 **Run workflow**（或推送代码后自动触发）。
3. 等待约 1~2 分钟构建完成，在页面底部 **Artifacts** 里下载 `BiliGamePiP-Windows-Installer`，解压即可得到 `BiliGamePiP-Setup-1.0.0.exe`。

### 方式二：在你的 Windows 电脑本地打包

1. 安装 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) 和 [Inno Setup 6](https://jrsoftware.org/isdl.php)。
2. 在项目根目录打开 PowerShell 运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1
   ```
3. 安装包会输出到 `dist\BiliGamePiP-Setup-1.0.0.exe`。
